# VibeWare terminal artwork

`vibeware-symbol.rgb` is the owner-supplied 20 by 20 floppy artwork used in
PromptMeUp, copied byte for byte for the WorkTrail CLI header. It is derived
from the owner's `vibeware-symbol-dark.png`; the source PNG SHA-256 is
`6CC171A8C60D3E92DE29FF0B45F9DE9F54E73532CEB5AE229720E0FD672FF535`.

The CLI shows the colored artwork only when there is room for the product text
beside it. Narrow or colorless output retains text and the manifesto link.
