# Planner authoring archive

This folder preserves scripts and intermediate data used while authoring the planner workbook.

The files are historical authoring material, not the normal user workflow. The supported user entry point is the workbook and the scripts documented in `01_support_scripts/README.md`.

Keep the archived scripts and generated data together when investigating how an earlier workbook was produced. Do not treat this folder as a second runtime or as a replacement for the current workbook.
